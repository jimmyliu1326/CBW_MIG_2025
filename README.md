# CBW_MIG_2025

This repository serves to archive the teaching materials used for the 2025 Canadian Bioinformatics Workshop on Microbial Genomics. All materials are located under [docs](https://github.com/jimmyliu1326/CBW_MIG_2025/tree/main/docs).

All materials in this repository are freely available for use, modification, and redistribution for any purpose. You are welcome to adapt these materials for your own applications. Please acknowledge this repository as the original source when sharing or publishing work derived from it.
